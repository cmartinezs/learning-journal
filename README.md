# Learning Journal

> Aprender con intención, practicar con criterio y demostrar comprensión.

Bitácora pública de aprendizaje profesional, que combina ingeniería de IA, arquitectura, producto y otras disciplinas que despierten curiosidad. **[Ver el catálogo ampliado de rutas](routes/catalog.md).**

No es otro proyecto de software. Los ejercicios y prototipos solo tienen sentido si ayudan a aprender.

## Método
1. Formular una pregunta antes de estudiar.
2. Explicar conceptos **con palabras propias**, sin copiar al instructor.
3. Practicar la recuperación activa y aplicar a casos nuevos.
4. Registrar errores, dudas y cambios de opinión.
5. Conservar una evidencia breve que demuestre la competencia.

**No medimos progreso por commits, videos vistos, líneas de código ni certificados.**

## Escala de dominio por competencia
| Nivel | Significado |
| --- | --- |
| 0 | Sin explorar |
| 1 | Reconozco el concepto |
| 2 | Puedo explicarlo con apoyo |
| 3 | Puedo aplicarlo autónomamente |
| 4 | Puedo justificarlo, compararlo y enseñarlo |

El nivel debe acompañarse de evidencia; no es una nota global ni un promedio.
